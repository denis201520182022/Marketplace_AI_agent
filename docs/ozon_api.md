# Официальная спецификация Ozon Seller API: Отзывы, Вопросы и Карточки товаров

Данный документ содержит полную техническую информацию, необходимую для разработки интеграционного коннектора Ozon в проекте AI-агента для селлеров маркетплейсов.

---

## 1. Базовые параметры и авторизация

### 1.1. Базовый URL
* **Production API:** `https://api-seller.ozon.ru`

### 1.2. Получение реквизитов доступа селлера
1. Селлер авторизуется в личном кабинете Ozon: [seller.ozon.ru](https://seller.ozon.ru/).
2. Переходит: *«Настройки» ➔ «API ключи»*.
3. Получает два параметра:
   * **`Client-Id`** — цифровой идентификатор аккаунта селлера (например, `123456`).
   * **`Api-Key`** — секретный API-ключ (создаётся с ролью «Администратор» либо с правами на «Товары», «Отзывы и вопросы»).

> **Важное бизнес-требование Ozon:** Методы работы с отзывами и вопросами на Ozon доступны для аккаунтов с активной подпиской **Premium / Premium Plus** или подключенной опцией **«Управление отзывами»**. При отсутствии подписки вызов методов отзывов вернёт ошибку доступа.

### 1.3. Передача заголовков в запросах
Все запросы к Ozon Seller API выполняются методом `POST` с обязательной передачей заголовков:
```http
Client-Id: <CLIENT_ID>
Api-Key: <API_KEY>
Content-Type: application/json
```

### 1.4. Ограничения частоты запросов (Rate Limiting)
* Стандартное ограничение Ozon: обычно **до 20–50 запросов в минуту** в зависимости от группы методов.
* При превышении лимита сервер возвращает HTTP-статус **`429 Too Many Requests`**.
* Формат ошибок Ozon возвращает JSON с кодом и описанием:
```json
{
  "code": 3,
  "message": "Too many requests",
  "details": []
}
```

## 2. API Отзывов (Reviews API)

### 2.1. Получение списка отзывов
**Метод:** `POST /v1/review/list` (или `/v2/review/list`)

#### Заголовки:
```http
Client-Id: <CLIENT_ID>
Api-Key: <API_KEY>
Content-Type: application/json
```

#### Тело запроса (JSON Body):
```json
{
  "page": 1,
  "page_size": 100,
  "sort_dir": "DESC",
  "status": "UNPROCESSED"
}
```

#### Поля запроса:
* `status` (`string`, обязательное) — статус отзывов:
  * `"UNPROCESSED"` — новые неотвеченные отзывы;
  * `"PROCESSED"` — отзывы, на которые уже дан ответ;
  * `"ALL"` — все отзывы.
* `page` (`integer`) — номер страницы (начиная с 1).
* `page_size` (`integer`) — количество элементов на странице (максимум 100).
* `sort_dir` (`string`) — направление сортировки: `"ASC"` или `"DESC"` (по дате публикации).

#### Пример успешного ответа (`200 OK`):
```json
{
  "result": [
    {
      "id": "01927515-707b-7567-ba54-16512319b43f",
      "sku": 18274619,
      "rating": 5,
      "text": "Отличные беспроводные наушники! Подключились мгновенно, звук чистый.",
      "pros": "Долгая батарея, качественный пластик",
      "cons": "Не нашел",
      "author_name": "Елена",
      "published_at": "2026-10-17T13:45:00Z",
      "status": "UNPROCESSED",
      "comments_count": 0,
      "photos": [
        "https://cdn1.ozone.ru/s3/multimedia-..."
      ],
      "order_status": "DELIVERED"
    }
  ],
  "has_next": false,
  "total": 1
}
```

---

### 2.2. Публикация ответа (комментария) на отзыв
**Метод:** `POST /v1/review/comment/create`

#### Тело запроса (JSON Body):
```json
{
  "review_id": "01927515-707b-7567-ba54-16512319b43f",
  "text": "Здравствуйте, Елена! Благодарим за выбор нашего бренда и тёплый отзыв. Рады, что наушники превзошли ваши ожидания. Приятного использования!",
  "mark_review_as_processed": true
}
```

#### Поля запроса:
* `review_id` (`string`, обязательное) — UUID идентификатор отзыва.
* `text` (`string`, обязательное) — текст ответа продавца.
* `mark_review_as_processed` (`boolean`, опционально) — автоматически перевести отзыв в статус обработанного (`PROCESSED`).
* `parent_comment_id` (`string`, опционально) — заполняется только при ответе на конкретный комментарий в треде.

> **Ограничение Ozon:** Нельзя оставить текстовый ответ на «пустой отзыв» (когда покупатель поставил оценку звёздами, но оставил текстовое поле и медиа пустыми). В таком случае Ozon возвращает ошибку `cannot comment on empty review`.

#### Пример ответа (`200 OK`):
```json
{
  "comment_id": "02927515-707b-7567-ba54-46522319b43c"
}
```

---

### 2.3. Получение детальной информации об отзыве
**Метод:** `POST /v1/review/info`

#### Тело запроса:
```json
{
  "review_id": "01927515-707b-7567-ba54-16512319b43f"
}
```

## 3. API Вопросов (Questions API)

### 3.1. Получение списка вопросов о товарах
**Метод:** `POST /v1/question/list`

#### Тело запроса (JSON Body):
```json
{
  "filter": {
    "status": "NEW"
  },
  "last_id": 0,
  "limit": 100
}
```

#### Поля запроса:
* `filter.status` (`string`): `"NEW"` (новые вопросы), `"ANSWERED"` (отвеченные), `"VIEWED"` (просмотренные).
* `limit` (`integer`): лимит элементов (до 100).
* `last_id` (`integer`): ID последнего полученного элемента для курсорной пагинации.

#### Пример ответа (`200 OK`):
```json
{
  "result": [
    {
      "id": 98765432,
      "sku": 18274619,
      "text": "Здравствуйте! Совместимы ли эти наушники с iPhone 15?",
      "author_name": "Игорь",
      "created_at": "2026-10-17T14:10:00Z",
      "status": "NEW",
      "answers_count": 0
    }
  ],
  "has_next": false,
  "total": 1
}
```

---

### 3.2. Публикация ответа на вопрос
**Метод:** `POST /v1/question/answer/create`

#### Тело запроса (JSON Body):
```json
{
  "question_id": 98765432,
  "sku": 18274619,
  "text": "Здравствуйте, Игорь! Да, наушники полностью совместимы со всеми моделями iPhone, включая 15 серию, через Bluetooth."
}
```

#### Поля запроса:
* `question_id` (`integer`, обязательное) — идентификатор вопроса.
* `sku` (`integer`, обязательное) — артикул (SKU) товара на Ozon.
* `text` (`string`, обязательное) — текст ответа селлера (от 2 до 3000 символов).

#### Пример ответа (`200 OK`):
```json
{
  "result": {
    "answer_id": 44556677
  }
}
```

## 4. Получение актуальной карточки товара (No-cache Context)

Для сбора полного контекста без кэширования коннектор Ozon вызывает методы получения описания и характеристик по `sku` / `product_id`.

### 4.1. Базовые данные карточки (Название, артикул, цена)
**Метод:** `POST /v2/product/info`

#### Тело запроса:
```json
{
  "sku": 18274619
}
```

#### Пример ответа:
```json
{
  "result": {
    "id": 12345678,
    "name": "Беспроводные наушники SoundMaster Pro",
    "offer_id": "HEADPHONE-PRO-BLACK",
    "price": "2990.00",
    "sku": 18274619,
    "visible": true
  }
}
```

---

### 4.2. Получение полного описания товара
**Метод:** `POST /v1/product/info/description`

#### Тело запроса:
```json
{
  "product_id": [12345678]
}
```

#### Пример ответа:
```json
{
  "result": [
    {
      "id": 12345678,
      "name": "Беспроводные наушники SoundMaster Pro",
      "description": "Полноразмерные наушники с поддержкой Bluetooth 5.3 и шумоподавления...",
      "short_description": "Беспроводные наушники с ANC и Type-C зарядкой"
    }
  ]
}
```

---

## 5. Типовые ошибки Ozon API и обработка

| Код ошибки | Сообщение / Причина | Действие коннектора |
| :--- | :--- | :--- |
| `HTTP 400` / Code 3 | Invalid argument (неверный ID, пустой комментарий) | Логирование, отметка задачи как ошибочной |
| `HTTP 401` / Code 16 | Access token is invalid or expired | Оповещение селлера в боте: «Неверный Api-Key Ozon» |
| `HTTP 403` / Code 7 | Permission denied (нет подписки Premium или прав) | Оповещение селлера: «Требуется подключить управление отзывами в Ozon» |
| `HTTP 429` / Code 8 | Rate limit exceeded | Экспоненциальный Backoff + перенос в Dead-Letter Exchange |
| `cannot comment on empty review` | Покупатель оставил только оценку без текста/фото | ИИ-агент не пытается писать ответ, помечает отзыв как обработанный |
| `HTTP 5xx` | Временный сбой Ozon | Повтор попытки через RabbitMQ retry |
